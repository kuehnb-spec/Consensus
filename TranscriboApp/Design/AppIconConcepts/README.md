# Consensus Icon Concepts

This folder contains four initial app icon directions for Consensus.

- `consensus-wave-split.svg`: circular signal mark, strongest audio-to-consensus read
- `consensus-privacy-shield.svg`: local-first/privacy emphasis
- `consensus-signal-knot.svg`: interlocking multi-pass reconciliation motif
- `consensus-monogram-grid.svg`: restrained premium monogram direction
- `index.html`: side-by-side comparison sheet

Open `index.html` in a browser or Quick Look to compare the set.
